# のり面カルテ 画面案

令和8年度 鹿児島県地域課題解決型衛星データ利活用実証事業の打合せ用の画面案です。

公開先: https://ryujiyasu.github.io/norimen-karte/

## 表示しているデータ

葉月工業から提供された元請工事一覧表（2026年9月15日版）のうち、地図の位置が記載された15件。
1件は「点在」のため座標が取れず、14件を読み込んでいます。
工事番号、発注者、工事名、路線、施工時期、工法と数量、規模、座標はすべて実データです。

## 二つの表示

- **台帳（実データ）** — いただいた工事一覧の中身と、衛星で追えるかどうかの判定。
- **解析後のイメージ** — 解析が終わるとこう見える、という見本。変位の数値はサンプルです。

衛星の解析はこれから行います。変位の数値はまだ実測ではありません。

## 判定の考え方

衛星の1画素はおおよそ40メートル四方。法長（または高低差）と延長から面の広がりを見て、
片方が40メートル以上あり、かつ面積が1200平方メートル以上のものを「衛星で追える」としています。
現時点では14件中5件が該当します。
